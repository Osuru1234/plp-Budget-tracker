
# SpendWise - Personal Budget Tracker

## Project Overview

SpendWise is a simple and user-friendly personal budget tracking web application designed to help users manage their money effectively. It allows users to set monthly budgets, record income and expenses, monitor spending, and track their remaining balance.

The application uses HTML, CSS, and JavaScript to provide an interactive and responsive user experience.

## Project Objectives

- Help users manage their monthly budgets.
- Track daily income and expenses.
- Monitor spending habits.
- Calculate remaining balances automatically.
- Encourage better financial planning and saving habits.

## Features

- Monthly budget setting.
- Income tracking.
- Expense tracking.
- Automatic balance calculation.
- Expense categorization.
- Transaction history.
- Delete transactions.
- Local Storage for saving transaction records.
- Responsive design for desktop and mobile devices.

## Technologies Used

- **HTML5:** Used to structure the application.
- **CSS3:** Used to style the application and create a responsive layout.
- **JavaScript:** Used to implement functionality and calculations.
- **Local Storage:** Used to save budget and transaction data in the browser.
- **GitHub:** Used for source code management and version control.
- **Netlify:** Used for website deployment.

## How to Run the Project

1. Download or clone the project repository.
2. Open the project folder.
3. Locate the index.html file.
4. Open index.html using a web browser such as Google Chrome.
5. Enter your monthly budget.
6. Add income and expenses.
7. Monitor your financial summary and transaction history.

## How It Works

1. Users enter their monthly budget.
2. Users record income and expenses.
3. The system automatically calculates total income.
4. The system calculates total expenses.
5. The remaining balance is updated automatically.
6. Transactions are saved using browser Local Storage.
